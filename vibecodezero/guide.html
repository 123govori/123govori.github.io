Твой ИИ-ассистент
за 4 шага

Установим VS Code, подключим Claude и создадим первый проект — прямо сейчас.

Шаг 1

Устанавливаем VS Code

VS Code — бесплатный редактор кода от Microsoft. Именно в нём будет жить твой ИИ-ассистент. Скачиваем и устанавливаем.

1

Скачай VS Code

Перейди на официальный сайт и скачай версию для своей системы. Нажми большую синюю кнопку — она автоматически определит твою ОС.

↗ Скачать VS Code
2

Установи как обычную программу

Открой скачанный файл и следуй инструкциям. На Windows — нажимай «Далее». На Mac — перетащи иконку в папку Applications.

💡

На Windows: поставь галочку «Добавить в PATH» — это пригодится позже.

3

Открой VS Code и создай рабочую папку

Запусти VS Code. Нажми File → Open Folder и выбери или создай папку для своих проектов. Например: Documents/мои-проекты

Шаг 2

Подключаем Claude

Claude Code — это официальное расширение Anthropic для VS Code. После установки Claude будет видеть все твои файлы и работать прямо в редакторе.

1

Установи расширение Claude Code

В VS Code слева нажми иконку Extensions (квадраты), в поиске введи Claude, найди расширение от Anthropic и нажми Install.

✦

Ищи именно «Claude» от Anthropic — официальный значок с белым ромбом на чёрном фоне.

2

Войди в аккаунт Anthropic

После установки расширение попросит авторизоваться. Нажми Sign in — откроется браузер, войди в свой аккаунт claude.ai или создай новый.

⚠️

Нужен Pro план ($20/мес) или API-ключ. Бесплатного аккаунта для работы в VS Code недостаточно. Самый простой вариант — Pro план.

3

Проверь что всё работает

После входа в левой панели VS Code появится иконка Claude. Нажми на неё — откроется чат. Напиши «Привет» — если ответил, всё готово.

Шаг 3

Первый проект с нуля

Теперь самое интересное — создаём реальный проект. Claude видит твою папку и может создавать файлы, писать код и исправлять ошибки.

1

Открой чат Claude в VS Code

Нажми на иконку Claude в левой панели. Убедись, что у тебя открыта рабочая папка — тогда Claude будет видеть все файлы в ней.

2

Дай первое задание

Опиши что хочешь создать. Чем подробнее — тем лучше. Вот пример хорошего запроса:

Пример запроса
Создай лендинг для фотографа. Структура: Hero с именем и кнопкой, галерея 6 фото (используй placeholder-изображения), блок «Обо мне», форма контакта. Стиль: тёмный фон, белый текст, золотые акценты. Сохрани всё в один файл index.html с CSS внутри.
💡

Главное правило: всегда проси сохранить в конкретный файл. Тогда Claude создаст файл прямо в твоей папке.

3

Claude создаёт файлы — ты проверяешь

Claude попросит разрешение создать файл — нажми Accept. Файл появится в твоей папке. Открой его двойным кликом в браузере.

🔁

Что-то не нравится? Просто напиши что изменить — не редактируй код вручную. Правь через запросы.

Теперь ты готов

У тебя есть все инструменты. Открой VS Code, создай папку и опиши свой первый проект.
